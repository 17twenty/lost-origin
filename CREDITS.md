# Credits

## Original work (this repo)
- The Wicker Man (player character): model, rig, animations — `tools/blender/build_wicker.py`; procedural weave (`shaders/wicker.gdshader`) and straw (`scripts/wicker_skin.gd`). Design follows the project's own turnaround (`wicker-inspo/turn-around-final.png`); the film stills in `wicker-inspo/` are weave/material reference only and the face is original.
- Wayfinder character, rig and animations — `tools/blender/build_character.py`
- Vegetation (coconut palms, tree fern, ferns, monstera, grass), garden tree, vines, totems — `tools/blender/build_plants.py`, `build_tree.py`, `build_vines.py`, `build_totem.py`; leaf/frond textures generated procedurally in `tools/level/plants.gd` / `garden.gd`
- Terrain, totems, aqueduct, grotto, facility geometry and shaders — generated by `tools/` scripts
